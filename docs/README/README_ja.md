## 一、私たちは誰か？

天機閣は、フリーソフトウェアの精神を核とし、オープンソース協力を方式とする開発者の集まりです。

私たちはいかなる商業企業、政治派閥、またはイデオロギー陣営にも属しません。私たちは私たち自身と、私たちが共に信じるものにのみ属します。

## 二、私たちは何を信じるか？

1. **コードは自由であるべき**
   私たちはGPLやAGPLなどのコピーレフトライセンスを使用し、ソフトウェアがユーザーに自由を与え、自由を奪うものではないことを確保します。

2. **人は尊重されるべき**
   貢献者が初心者であれベテランであれ、どの国から来ていようと、どんな言語を話そうと、肌の色がどうであれ、学歴の高低に関わらず——コードの前では、コードそのものだけを認めます。

3. **善意は本物である**
   私たちは前提条件も見返りも求めず、自ら創造したものをあなたと共有します。

4. **we hate hate**
   年齢、体型、障害、民族、性別の特徴、性自認と表現、経験レベル、教育、社会経済的地位、国籍、外見、人種、宗教、または性的指向に基づくすべてのヘイトスピーチを拒否します。

## 三、私たちは何をするか？

1. オープンソース／フリーソフトウェアプロジェクトを作る：動き、問題を解決し、他者を助けるコードを生み出す。
2. 互いに支え合う：メンバー間でコードは批判できるが人を攻撃しない；技術は議論できるが立場に昇格させない；疲れたら休んでいいが、走り続ける人を嘲笑しない。
3. 外との繋がり：他のオープンソースチームや他国の開発者と協力する。

## 四、私たちは何を与えられるか？

1. 異なる人が同じ目標に向かって共に歩める場所。
2. 味方を選ばなくていい場所。
3. 世界を変えられる場所。

## 五、私たちの協力方式は何か？

1. **技術問題**：最も技術力がある、またはその分野に最も注力している人が主導して決定するが、公開議論が必要。
2. **方向問題**：コアメンバーの協議で決定する。誰でも反対意見を出せるが、反対する際は代替案も提示する必要がある。
3. **参加方法**：原則として「申請チャンネル」は設けない。新メンバーは既存メンバーの紹介を通じ、一定期間の協力の後、チームのコンセンサスで決定する。
4. **退出方法**：疲れたら休み、回復したら戻る。永久に退出する場合は、維持している部分を引き継ぐだけでよい。引き留めず、責めない。
5. **意見の相違**：issueを開いて議論する。合意に達しない場合、フォークしてそれぞれ試し、結果で示す。
6. **理念の相違**：核心的価値観に戻る。それでも調和できない場合、友好的に別れる。世界は広い、一つの木に縛られる必要はない。

## 六、私たちの役割分担は何か？

**閣主**
なし。今も未来もない。権力は長期占有されるべきではなく、方向はコンセンサスによって推進されるべき。

**代理閣主（baby2016）**
最終決定、対外代表、方向の把握、チームが共有する価値観から逸脱しないことを確保する責任を負う。代理閣主は罷免されることも、自ら譲ることもできる。

**長老**
- チームに継続的に時間を投じ、信頼を獲得し、ある側面で核心的な責任を担うメンバー。
- チームの重大な決定に参加する（例：大型貢献の受け入れ、ライセンス方針の変更）。
- 自分の得意分野で技術方向の決定権を持つ。
- 代理閣主が過ちを犯した場合、長老は反対する権利がある；重大な過ちの場合、全長老が共同して代理閣主を罷免できる。

**客卿**
時折貢献する、または長期参加しない友人。彼らは私たちが大切にする縁である。

## 七、私たちの底線は何か？

厳禁：
- チームのコードまたはその派生物を、元のライセンスに違反する方法でクローズドソースにする、または私有化する。
- 「天機閣」の名を騙って違法活動や商業詐欺を行う。
- チームのいかなるコミュニケーションチャンネルでも、ヘイトスピーチを行う（再強調）。

## 八、私たちは何を追求するか？

天機閣は規模も資金調達も多くの人に知られることも追求しない。私たちが追求するのは：
- 私たち自身が満足する、真に自由なソフトウェアまたはプロジェクトを書くこと。
- 人が共通の信念と善意に基づいて、他者にとって価値あるものを創造できることを証明すること。
- **Connect The World**——世界をつなぐ、自由と善意を信じるすべての人をつなぐこと。

## 九、私たちの未来は何か？

本文の著者として正直に言えば——私にも分からない。
でもいつか、私たちのメンバーがネットワークから出て、世界中で同好の人々と出会い、コードを書き、そして大笑いすることを願っている。
